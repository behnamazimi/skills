# Language-learning checks

Add these to the content lens findings.

- Minimum payload per item for its task: translation or definition, part of
  speech or article, example, audio, difficulty tag. Present where the task
  needs it, expandable elsewhere.
- Scaffolding that fades as proficiency grows.
- Feedback moments carrying enough to reinforce memory and little else; a
  wrong answer explains why.
- Examples that are real usage.
- Progressive disclosure applied the same way on every screen showing an
  item.
- Streaks, points or lives beside the vocabulary task: do they compete with
  it?
